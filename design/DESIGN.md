# dan-c.co.uk — design direction

**Positioning:** Public track record + method for a systematic forex day-trading robot. Course waitlist next. Signals only after a live track record (soft-launch later).

**Look:** Fintech clarity. Trust over hype. Calm slate + teal. Not crypto-bro, not get-rich.

## Colour
| Token | Hex | Use |
|-------|-----|-----|
| bg | `#F7F8FA` | Page |
| surface | `#FFFFFF` | Cards |
| ink | `#0F172A` | Headings / body |
| inkMuted | `#475569` | Supporting |
| accent | `#0D9488` | CTAs, chart line, links |
| positive / negative | `#047857` / `#B91C1C` | Soft tints only in tables |

## Type
- **UI/body:** Inter (or system sans)
- **Numbers:** tabular figures; JetBrains Mono optional for trade IDs
- Display ~2.5rem / H1 2rem / body 1rem — generous line-height

## Priority pages
1. **Home** — one promise, proof snapshot (3 stats + mini equity), CTAs
2. **Results** — equity curve, KPIs, monthly returns, disclaimer always visible
3. **Method** — rules overview (markets, session, risk) without dumping signals
4. **Course** — waitlist email capture for “build trading robots”
5. **About** — who / UK / what this site is not (not advice)

## Key components
- **Equity chart:** teal stroke, light grid, range pills, calm caption
- **Disclaimer:** slate band near every performance claim + footer link to full disclosure
- **CTAs:** primary filled teal; secondary text link
- **Nav:** top marketing nav (not app sidebar) for the public site
